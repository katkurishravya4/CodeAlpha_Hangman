# 🎮 Hangman Game

A simple console-based Hangman Game developed in Python as part of the **CodeAlpha Python Programming Internship – Task 1**.

The game randomly selects a word from a predefined list, and the player must guess the word one letter at a time. The player is allowed a maximum of **6 incorrect guesses**.

---

## 📌 Project Overview

Hangman is a classic word-guessing game where the player tries to reveal a hidden word by guessing individual letters.

In this project:

- A word is randomly selected from a predefined list.
- The letters of the word are initially hidden using underscores (`_`).
- The player enters one letter at a time.
- Correct guesses reveal the corresponding letters.
- Incorrect guesses are counted.
- Repeated guesses are detected.
- The game ends when the player guesses the complete word or reaches 6 incorrect guesses.
